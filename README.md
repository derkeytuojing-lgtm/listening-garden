# สวนรับฟัง

ดับเบิลคลิก **ListeningGarden.exe** บน Windows พิมพ์เลขเมนูแล้วกด Enter เลือก 1 เพื่อเริ่มเรื่องทันที หรือเลือก 2 เพื่ออ่านวิธีเล่นและสูตรผสมทั้ง 12 สูตรก่อนเปิดร้าน

## ลองเล่าตอนนำเสนอ

“เราเปิดร้านรับฟังเรื่องของลูกค้า พอคุยจบก็ได้ผลึกมาเลี้ยงต้นไม้ คำตอบที่เลือกเปลี่ยนบทสนทนา แต่ลูกค้ายังให้ผลึกเท่าเดิม ตอนเย็นเราต้องตัดสินใจเองว่าจะใช้ผลึกชิ้นไหนตรง ๆ หรือเอาสองชิ้นมาผสมกัน”

เปิด `main.c` แล้วเริ่มอ่านจากฟังก์ชัน `main` ที่ท้ายไฟล์

1. `new_day` สุ่มอากาศกับชุดผลึก แล้วลองปลูกในแผนจำลองเพื่อเก็บเฉลย
2. `meet_customers` ใช้ลูป `for` รับลูกค้า 8 คนต่อจากป้าอิง แต่ละคนมีเรื่อง ผลึก และจำนวนของฝากประจำรอบ
3. `planting` ใช้ลูปรอเลขเมนู ถ้าใช้ตรงก็เลือกจำนวนได้ แต่ละชิ้นเพิ่ม 10 หน่วย ถ้าผสมก็หักสองชิ้น แล้วบวก 10 ให้ส่วนที่เลือก
4. `grow_tree` ใน growth.c วาดภาพจุดทีละภาพ เว้นจังหวะประมาณครึ่งวินาที แล้ววาดภาพถัดไปที่เดิม
5. `morning` แสดงต้นไม้และบทส่งท้าย จากนั้นให้ดูคะแนน เฉลย และเลือกเล่นต่อ

## ตัวอย่างให้ลองวาดบนกระดาษ

สมมติคลังมีผลึกกลุ่มใบ 5 ชิ้น ราก 5 ชิ้น เปลือก 2 ชิ้น เป้าคือให้ต้นไม้ได้ 30 หน่วยทั้งสามด้าน

- ใช้ตรง ๆ ตามลำดับ ใบ 3 ชิ้น ราก 3 ชิ้น เปลือก 2 ชิ้น ตอนนี้ต้นไม้มี **30 / 30 / 20**
- หยิบผลึกใบกับรากอย่างละชิ้นมาผสม เช่น สุข + กลัว ได้ “กล้าหาญ” เติมเปลือกอีก 10
- ตอนนี้ต้นไม้มี **30 / 30 / 30** ส่วนคลังยังเหลือใบกับรากอย่างละชิ้น ผ่านได้ทุกสภาพอากาศและได้ Perfect

## เกมสุ่มวันอย่างไร

ทุกครั้งที่จับฉลาก เกมขอเลขจาก Windows ผ่าน `rand_s` และตัดค่าปลายช่วงที่ทำให้บางเลขออกบ่อยกว่าเลขอื่น วันใช้ตรงมีโอกาส 40% วันผสมหนึ่งครั้ง 40% และวันผสมสามครั้ง 20% ส่วนพายุ แล้ง และแมลง มีโอกาสอย่างละหนึ่งในสาม รอบติดกันจึงเจออากาศเดียวกันได้

เกมกันผลึกให้พอปลูกสมดุลก่อน แล้วสุ่มจัดผลึกอีกส่วนให้ลูกค้า สลับลำดับคนเข้าร้าน และลองทำสูตรให้ได้ Perfect ก่อนเปิดวันนั้น ตอนจัดแผนกด 7 เพื่อเลือกสูตรจากของที่เหลืออยู่ได้

## ตัวแปรที่ควรรู้

`bag[6]` เก็บจำนวนผลึกดิบแต่ละชนิด ส่วน `value[3]` เก็บหน่วยใบ ราก และเปลือกตามลำดับ สองอาร์เรย์นี้อยู่ใน `Plan` เดียวกัน การส่ง `&plan` ให้ฟังก์ชันคือส่งที่อยู่ของแผน เพื่อให้ฟังก์ชันแก้แผนที่กำลังเล่นได้

ดู `apply` และ `undo` คู่กันใน `garden.c` เมื่อใส่ผลึก โปรแกรมจดวัตถุดิบไว้ใน `moves` พอกดย้อน ก็อ่านรายการสุดท้าย คืนวัตถุดิบ แล้วหัก 10 หน่วยออก

`stories.c` เก็บบทพูด แก้ข้อความตรงนี้ได้ ส่วน `garden.h` บอกว่าข้อมูลของวัน แผน และผลคะแนนมีอะไรบ้าง

## คอมไพล์ด้วย GCC

เปิดเทอร์มินัลในโฟลเดอร์เกมแล้วรัน

```powershell
gcc -std=c11 -Wall -Wextra -O2 main.c garden.c stories.c growth.c -o ListeningGarden.exe -lm
.\ListeningGarden.exe
```

ทดสอบกติกาแยกจากเกมด้วย `gcc -std=c11 test_garden.c garden.c stories.c -o test_garden.exe -lm` แล้วรัน `.\test_garden.exe`
