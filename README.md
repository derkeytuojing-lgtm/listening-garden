# สวนรับฟัง

ดับเบิลคลิก **ListeningGarden.exe** บน Windows พิมพ์เลขเมนูแล้วกด Enter เลือก 1 เพื่อเริ่มเรื่องทันที หรือเลือก 2 เพื่ออ่านวิธีเล่นและสูตรผสมทั้ง 12 สูตรก่อนเปิดร้าน

## ลองเล่าตอนนำเสนอ

“เราเปิดร้านรับฟังเรื่องของลูกค้า พอคุยจบก็ได้ผลึกมาเลี้ยงต้นไม้ คำตอบที่เลือกเปลี่ยนบทสนทนา แต่ลูกค้ายังให้ผลึกเท่าเดิม ตอนเย็นเราต้องตัดสินใจเองว่าจะใช้ผลึกชิ้นไหนตรง ๆ หรือเอาสองชิ้นมาผสมกัน”

เปิด `main.c` แล้วเริ่มอ่านจากฟังก์ชัน `main` ที่ท้ายไฟล์

1. `new_day` สุ่มอากาศกับชุดผลึก แล้วลองปลูกในแผนจำลองเพื่อเก็บเฉลย
2. `meet_customers` ใช้ลูป `for` รับลูกค้า 8 คนต่อจากป้าอิง แต่ละคนมีเรื่อง ผลึก และจำนวนของฝากประจำรอบ
3. `planting` ใช้ลูปรอเลขเมนู ถ้าใช้ตรงก็เลือกจำนวนได้ แต่ละชิ้นเพิ่ม 10 หน่วย ถ้าผสมก็หักสองชิ้น แล้วบวก 10 ให้ส่วนที่เลือก
4. `grow_tree` ใน growth.c วาดภาพจุดทีละภาพ เว้นจังหวะประมาณครึ่งวินาที แล้ววาดภาพถัดไปที่เดิม
5. `morning` แสดงต้นไม้และบทส่งท้าย จากนั้นให้ดูคะแนน เฉลย และเลือกเล่นต่อ

## ตัวอย่างให้ลองวาดบนกระดาษ

สมมติคลังมีผลึกกลุ่มใบ 5 ชิ้น ราก 5 ชิ้น เปลือก 2 ชิ้น เป้าคือให้ต้นไม้ได้ 30 หน่วยทั้งสามด้าน

- ใช้ตรง ๆ ตามลำดับ ใบ 3 ชิ้น ราก 3 ชิ้น เปลือก 2 ชิ้น ตอนนี้ต้นไม้มี **30 / 30 / 20**
- หยิบผลึกใบกับรากอย่างละชิ้นมาผสม เช่น สุข + กลัว ได้ “กล้าหาญ” เติมเปลือกอีก 10
- ตอนนี้ต้นไม้มี **30 / 30 / 30** ส่วนคลังยังเหลือใบกับรากอย่างละชิ้น ผ่านได้ทุกสภาพอากาศและได้ Perfect

## เกมสุ่มวันอย่างไร

ทุกครั้งที่จับฉลาก เกมขอเลขจาก Windows ผ่าน `rand_s` และตัดค่าปลายช่วงที่ทำให้บางเลขออกบ่อยกว่าเลขอื่น วันใช้ตรงมีโอกาส 40% วันผสมหนึ่งครั้ง 40% และวันผสมสามครั้ง 20% ส่วนพายุ แล้ง และแมลง มีโอกาสอย่างละหนึ่งในสาม รอบติดกันจึงเจออากาศเดียวกันได้

เกมกันผลึกให้พอปลูกสมดุลก่อน แล้วสุ่มจัดผลึกอีกส่วนให้ลูกค้า สลับลำดับคนเข้าร้าน และลองทำสูตรให้ได้ Perfect ก่อนเปิดวันนั้น ที่โต๊ะปลูก กด 1 แล้วเลือกใบ ราก หรือเปลือก เกมจะแสดงเฉพาะผลึกและสูตรที่ใช้กับส่วนนั้นได้ กด 2 เพื่อดูต้นไม้ คลังผลึก คู่มือ หรือย้อนแผน พอพอใจแล้วกด 3 เพื่อปลูก

## ตัวแปรที่ควรรู้

`bag[6]` เก็บจำนวนผลึกดิบแต่ละชนิด ส่วน `value[3]` เก็บหน่วยใบ ราก และเปลือกตามลำดับ สองอาร์เรย์นี้อยู่ใน `Plan` เดียวกัน การส่ง `&plan` ให้ฟังก์ชันคือส่งที่อยู่ของแผน เพื่อให้ฟังก์ชันแก้แผนที่กำลังเล่นได้

ดู `apply` และ `undo` คู่กันใน `garden.c` เมื่อใส่ผลึก โปรแกรมจดวัตถุดิบไว้ใน `moves` พอกดย้อน ก็อ่านรายการสุดท้าย คืนวัตถุดิบ แล้วหัก 10 หน่วยออก

`stories.c` เก็บบทพูด แก้ข้อความตรงนี้ได้ ส่วน `garden.h` บอกว่าข้อมูลของวัน แผน และผลคะแนนมีอะไรบ้าง

## อธิบายไฟล์ส่งงาน

ส่ง `share/ListeningGarden.c` ไฟล์เดียว เปิดอ่านจาก `main()` ท้ายไฟล์ก่อน ลองเล่าตามหนึ่งรอบที่เล่น แล้วค่อยเปิดฟังก์ชันของช่วงนั้นให้ดู

| ส่วน | ทำอะไรและทำไม |
|---|---|
| `#include` | `stdio.h` อ่านเลขเมนูและพิมพ์ข้อความ · `stdbool.h` ใช้จริง/เท็จกับคำถามอย่าง “ปลูกได้ Perfect ไหม” · `stdlib.h` ใช้เลขสุ่มของ Windows และจบโปรแกรมเมื่อปิดทางรับข้อมูล · `windows.h` ตั้ง UTF-8 และควบคุมจังหวะภาพในคอนโซล |
| `#ifdef _WIN32` | เลือกส่วนที่ใช้ได้บน Windows ตอนคอมไพล์ ส่วน `_CRT_RAND_S` ขอให้ไลบรารีบน Windows ประกาศฟังก์ชันสุ่ม `rand_s` |
| `Story`, `Day`, `Plan`, `Result` | ใช้ struct เก็บข้อมูลที่เกี่ยวกัน เช่น คลังผลึกกับรายการที่เคยใส่อยู่ในแผนเดียวกัน ลองชี้ความต่างระหว่าง “ของที่ยังเหลือ” กับ “หน่วยที่ต้นได้รับ” |
| `draw`, `shuffle` | จับเลขแล้วสลับลำดับลูกค้า ตัวอย่างสุ่ม 3 ทางจาก 256 ค่า ใช้เฉพาะ 0–254 เพราะแบ่งได้ทางละ 85 ค่า ถ้าได้ 255 ให้จับใหม่ |
| `find_answer` | ทดลองในสำเนาคลัง ผสมตามจำนวนครั้งของวัน เติมตรงกลุ่มให้ครบด้านละ 30 แล้วตรวจด้วยสูตรคะแนนเดียวกับผู้เล่น จึงเปิดเผยเฉลยที่ทำตามได้จริง |
| `feed_group`, `apply`, `undo` | เมนูสร้างรายการจากผลึกที่มี เมื่อผู้เล่นตกลงจึงหักวัตถุดิบและจดรายการ กดย้อนก็อ่านรายการล่าสุดแล้วคืนของ |
| `evaluate` | หาค่าน้อยสุดกับมากสุดเพื่อวัดสมดุล แล้วเทียบรากและเปลือกกับเกณฑ์อากาศ หน่วยที่ขาดหนึ่งหน่วยทำให้สุขภาพลดสอง |
| `welcome`, `grow_tree` | หน้าเมนูแสดงต้นไม้ ส่วนรูปป้าอิงเป็นข้อความจุดที่พิมพ์ตอนเริ่มเนื้อเรื่อง ส่วนต้นไม้มีหลายภาพ โปรแกรมวาดทับตำแหน่งเดิมทีละภาพ |
| `visitor_returns` | ดูว่าผู้เล่นใช้ผลึกอะไร ย้อนไปหาลูกค้าที่เคยให้ผลึกชิ้นนั้น แล้วเลือกบทพูดของคนนั้นมาเล่าตอนเช้า |

คอมไพล์ไฟล์ส่งงานด้วย `gcc -std=c11 ListeningGarden.c -o ListeningGarden.exe` ในโฟลเดอร์ที่เก็บไฟล์

## คอมไพล์ด้วย GCC

เปิดเทอร์มินัลในโฟลเดอร์เกมแล้วรัน

```powershell
gcc -std=c11 -Wall -Wextra -O2 main.c garden.c stories.c growth.c -o ListeningGarden.exe
.\ListeningGarden.exe
```

ทดสอบกติกาแยกจากเกมด้วย `gcc -std=c11 test_garden.c garden.c stories.c -o test_garden.exe` แล้วรัน `.\test_garden.exe`
